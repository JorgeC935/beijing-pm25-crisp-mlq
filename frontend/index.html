PRIMER ENTRENAMIENTO

Entrenamiento inicial

Si la base está vacía, selecciona el CSV histórico original de Wanliu. Si el histórico ya está guardado en PostgreSQL, el sistema lo reutilizará sin volver a importarlo.

Se utiliza el histórico UCI de 35.064 registros. El entrenamiento inicial se realiza una sola vez.

ACTUALIZACIÓN DEL MODELO

Reentrenamiento

Combina el histórico original con las nuevas mediciones registradas individualmente y evalúa un modelo candidato.

Desde una medición nueva con objetivo conocido a +6 h, se ajusta un candidato con el histórico de entrenamiento y los ejemplos nuevos. Ambos modelos se comparan en una referencia histórica reservada, sin usarla para el ajuste. La comparación y cualquier promoción son demostrativas, no una validación de rendimiento futuro.
